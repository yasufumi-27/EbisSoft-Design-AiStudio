# ブランド素材（ロゴ・名刺）

印刷・資料用の素材です。**サイトには配信されません**（`public/` の外に置いてあります）。

ロゴの文字は、画面のロゴ（`src/components/site/CompanyLogo.tsx`）とまったく同じ
Geist Black の輪郭（`src/components/fx/logoFont.json`）から起こしています。名刺と画面でロゴがずれません。

| 種類 | 正データ | 直し方 |
| --- | --- | --- |
| ロゴ単体 | `logo/*.svg`（PNGはその書き出し） | `python3 scripts/brand-assets.py` で作り直す |
| 名刺 | `meishi/meishi.html` | **このHTMLを手で書き換える**（スクリプトは触りません） |

## ロゴ単体 — `logo/`

| ファイル | 中身 | 使いどころ |
| --- | --- | --- |
| `yebisu-soft-mark.svg` / `.png` | マークのみ（**背景透過**・正方形 2048px） | 資料の隅、印章的な使い方 |
| `yebisu-soft-mark-navy.svg` / `.png` | マークのみ（ネイビーの角丸地・2048px） | SNSのアイコン、アプリアイコン |
| `yebisu-soft-logo-horizontal-onlight.svg` / `.png` | マーク＋ワードマーク（**背景透過**／`YEBISU` はネイビー・2600px） | 白・薄い色の紙面、白背景のスライド |
| `yebisu-soft-logo-horizontal-ondark.svg` / `.png` | マーク＋ワードマーク（ネイビー地／`YEBISU` は白・2600px） | 濃色背景のスライド、封筒 |

ワードマークは `YEBISU`（白またはネイविー）＋ `SOFT`（シアン `#22d3ee`）。
**社名の英字表記を使ってよいのはロゴだけ**で、本文・見出しはカタカナの「エビスソフト」です。

## 名刺 — `meishi/meishi.html`

**この1ファイルが名刺の元データです。**社員が増えたり、メールを載せる／載せないを切り替えたりを
手作業でやる前提なので、あえてHTML1枚にまとめてあります（画像ではないので文字を直接直せます）。

- 仕上がり **91 × 55mm**（日本の標準サイズ）
- **裁ち落とし（塗り足し）各3mm** 込みで 97 × 61mm
- 文字は仕上がりから4mm内側（安全枠）に収めてあります
- ロゴはインラインSVG（実データ）なので、拡大しても滲みません

### 編集のしかた（ブラウザでそのまま直せます）

`meishi.html` をブラウザで開くと、その場で編集できます。パワポと同じ感覚で触れます。

| やりたいこと | 操作 |
| --- | --- |
| 文字を直す | 直したいところを**ダブルクリック**して打ち替える。終わったら名刺の外をクリック |
| 位置を動かす | 1回クリックで選んで、そのまま**ドラッグ**。矢印キーで0.5mm（Shiftで0.1mm）ずつ |
| 大きさ・色・太さ・行揃え | 選んでから上のバーで変える |
| 行を足す／消す | 「＋ 文字を足す」／選んで「削除」または Delete キー |
| 元に戻す | 「元に戻す」または ⌘Z（文字入力中はその場の取り消し） |
| 載せない項目 | その箱を削除するか、`class` に `hidden` を足す |
| **保存** | 「保存（HTMLを書き出し）」→ ダウンロードされた `meishi.html` でこのファイルを差し替える |

**社員を増やすとき**は、氏名・肩書だけ直して保存し、`meishi-<名前>.html` として保存するのが簡単です。
テキストエディタで直接HTMLを書き換えてもかまいません（位置は各箱の `style="left:…mm;top:…mm"`）。

赤い線が仕上がり、青い破線が安全枠です（画面だけに出ます）。文字は青い破線の内側に置いてください。

### 色を変える

色は先頭の `:root{ … }` にCSS変数としてまとまっていて、**そこだけ直せば表・裏・ロゴまで変わります**。

上のバーの「色」タブでカラーピッカーを動かすとその場で反映され、**そのまま「保存」すればその色で書き出されます**
（`<html>` のstyleとして保存されます）。CSSに残したい場合は「この色をCSSとしてコピー」で
出てくる `:root{ … }` をファイル先頭のものと差し替えてください。

### QRコード

表のQRは `https://www.yebisusoft.jp/` です。誤り訂正レベルQ（30%まで復元）で、白い下敷きに載せてあります
（濃い地に直接置くと読めない機種があるため）。**リンク先を変えるときは**
`python3 scripts/brand-assets.py --reset-meishi` で作り直してください
（画面で文字を打ち替えてもQRの中身は変わりません）。

QRは `scripts/qrcode_min.py` で生成しています。`python3 scripts/qrcode_min.py` を実行すると、
作ったQRを別実装のデコーダで読み戻す往復テストと、誤り訂正符号の検証が走ります。

### 印刷・PDF・FAX

上のバーの「印刷」で3通りから選べます（`<body class="...">` を直接書き換えてもOK）。

| モード | body の class | 用紙 | 用途 |
| --- | --- | --- | --- |
| 入稿用 | `mode-cut` | 97 × 61mm × 2ページ | 印刷所に渡すPDF。裁ち落とし3mm込み |
| A4に10面付け | `mode-a4` | A4 × 1ページ | 自分のプリンタで刷って切る。薄い線が切る目印 |
| FAX・モノクロ | `mode-fax` | A4 × 1ページ | **白地に黒だけ**・1.6倍。FAX送信やコピー用 |

「印刷 / PDF」ボタン（または ⌘P）→ 用紙サイズは選んだモードのものが自動で入ります。
**「背景のグラフィック」をON、拡大縮小100%** にしてPDFで保存してください。
3モードとも、出力PDFの用紙サイズを実測して確認済みです。

FAXモードでは背景の塗りと軌道リングが消え、ロゴも含めて黒一色になります（FAXは中間調がつぶれるため）。
色の指定は `body.mode-fax{ … }` にまとまっています。

- 和文は `Hiragino Sans` などシステムフォント参照です。PDFにすれば埋め込まれるので入稿先の環境を問いません。
- 色はRGBです。CMYK指定を求められたら、ネイビー `#0f2e5f`／シアン `#22d3ee`／赤 `#a51f38` を
  近似値に変換してもらってください。
- 掲載内容を変えたら、サイト側（`src/lib/site.ts`・`src/lib/author.ts`）と食い違わないか確認してください。
