## 実装内容

- キャラクターの元画像を保持し、表示サイズ別のWebP画像を追加。
- スマホの常駐クロマは581,496 → 9,304 bytes。128px版と256px版を画面密度に応じて配信。
- クロマ・エビスさんのポートレートは160 / 320 / 640px版を用意。衣装・元の縦横比・トリミング・透過・アニメーションを維持。
- 初期画面の本文はJavaScriptの起動を待たずに表示。画面外のコンテンツにスクロール出現演出を設定。
- デザイン案のテーマCSSは使うページで読み込み。新しいコーナーのリンク先を自動先読みせず、初期表示の通信を優先。
- 画面外のセクションはcontent-visibilityで描画を遅延。本文はDOMに保持し、画面に近づくと描画する。
- HTMLに対応するCSSをビルド時に抽出してインライン化。完全なCSSも非同期で読み込み、操作後の状態・ページ遷移に必要なルールを保持。JavaScript無効時はnoscriptで通常のCSSを読み込む。
- data-enterが真偽値の場合に出現演出のdelayがNaNになる不具合を修正。
