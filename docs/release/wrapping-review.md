# 全ページの改行レビュー — 2026-09-17

## 修正

- 文字数で強制分割していた組版処理を、BudouXの日本語モデルによる文節区切りへ変更。「仕組み」「問い合わせ」「組み込み」「コンフィギュレーター」などを途中で分割しない。
- 見出し、本文、カード、キャラクター案内、FAQ、リンク・ボタン、デモ操作画面に同じ処理を適用。初期HTMLとクライアントで同じモデルを使い、描画後のDOM書き換えは行わない。
- 装飾用spanのCSSを拾わない中立のインライン要素とwbrを使用。文字列にゼロ幅文字を挿入せず、コピーした文章・リンク先・読み上げ用属性を保つ。
- スマホのデモ注意書きの過剰な左右余白を除去。業種別お知らせは日付・分類と本文を別の行にし、タブレットのカード幅を確保。
- 業種別デモのナビは1280px未満でメニュー表示。開閉部分が告知バーに隠れないようヘッダーを通常配置に変更。
- フォームの必須表示をラベル横に固定。長い複合見出しや短い末尾だけが残る補足も調整。
