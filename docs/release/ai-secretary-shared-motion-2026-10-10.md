# AI秘書ページ：サイト共通のアニメーションへ統一

2026-10-10。対象は `/ai-secretary`。GitHub Pagesで確認し、さくら本番への公開は行わない。

## 変更

独自の簡易演出を撤去し、既存の `CharacterStage`、`CharacterGuide`、`Figure`、`StudioHome.module.css` とサイト共通CSSを使う。冒頭の粒子、キャラクターの浮遊、ポインターへの傾き・発光、ボタンの追従、スクロール時の出現・進捗表示を既存ページと揃える。基本3機能には共通の交互配置の図解を使用する。

Reactの `StudioMotion` が持っていた実装を `src/lib/studio-motion.ts` に抽出。Reactページと静的なAI秘書ページの両方が同じ実装を使用する。静的ページ用JSはビルド時にTypeScriptから生成する。粒子数、30fpsの描画上限、出現時間1秒、イージングは変更していない。動きを止める操作、OSの動きを減らす設定、画面外・非表示タブでの停止に対応する。

キャラクター画像は表示サイズに合った候補を選び、冒頭の画像を優先読み込みする。AI秘書ページでは使用する共通CSSを抽出し、CSS Modulesの識別名のみ短縮。必要なスタイルをHTMLへ埋め込み、追加のCSSリクエストを不要にする。本文・目次・FAQ・料金は静的HTMLのまま。計測時だけ演出・解析を無効にする分岐はない。

## 検証

証拠保存先：`output/ai-secretary-shared-review/`。

- `npm run lint`、本番形式の静的ビルド、エクスポート監査。
- 375 / 768 / 1440pxでAI活用ページと比較。カード寸法・角丸・書体・行高・浮遊時間・イージングの一致、粒子の描画更新、横スクロールなしを確認。
- 動きの停止・再開、OSの動きを減らす設定を確認。
- トップ、Web制作、組込み、AI秘書で共通エンジンの傾き・1秒の出現・スクロール進捗を確認。コンソールエラーなし。
- JavaScript無効でも本文とFAQを利用可能。GA設定の実行を確認。
- 本番canonical、h1一つ、FAQ10件とJSON-LDの一致、Service等の構造化データ、16件の内部リンクを確認。
- 料金は初期100万円〜・運用保守月額10万円（税別）。80時間×12,500円の根拠、基本3機能、契約範囲・追加料金の説明を保持。

Lighthouseは本番形式の成果物をローカルHTTP・無圧縮で配信し、モバイル既定条件とdesktop presetで各3回実施。GA・共通アニメーションを有効にした状態で測定。途中の98〜99点の記録も `before-*` ディレクトリに保持し、最終成果物の計測と区別する。公開サーバーの実測値ではない。GitHub Pagesは検索重複を避けるnoindex設定を維持する。
